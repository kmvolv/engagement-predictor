This project was taken up to evaluate the performance of fine-tuned multimodal models in carrying out the prediction of engagement scores based on the thumbnail and text descriptions of a social media post. The data used to train the model was obtained through the [PixelRec](https://github.com/westlake-repl/PixelRec) dataset.

A detailed description of the methodology and background of the project can be found in `Project_Report.pdf`.

This was part of COMS 6720: Advanced topics in Artificial Intelligence through Iowa State University.
